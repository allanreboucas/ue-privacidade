Ue Como Assim Dados

Ferramenta interna do canal do YouTube "Ué, como assim?" (@ueversotv). Ela lê as estatísticas do próprio canal para o dono do canal acompanhar o desempenho dos vídeos. Não é oferecida a outras pessoas.

Política de privacidade

Atualizada em 2 de novembro de 2026.

Quais dados são lidos. Com a autorização do dono do canal, a ferramenta usa a YouTube Data API e a YouTube Analytics API para ler dados do próprio canal: lista de vídeos, títulos, visualizações, tempo assistido, inscritos e números de público agregados e anônimos que o YouTube Studio já mostra.

Como são usados. Só para relatórios internos de desempenho do canal. Os dados ficam no computador do dono do canal.

Compartilhamento. Nenhum dado é vendido, compartilhado ou enviado a terceiros.

Dados de outras pessoas. A ferramenta não coleta dados pessoais de espectadores; trabalha só com números agregados fornecidos pelo YouTube.

Revogar o acesso. O acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions.

O uso dos dados segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Termos de uso

Uso restrito ao dono do canal "Ué, como assim?". Não há serviço oferecido ao público.
